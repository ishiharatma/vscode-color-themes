Plain Text Sample
=================

This file has no syntax highlighting. Use it to check the basic editor colors:
the background, the foreground, line numbers, the cursor, selection,
find matches, and the minimap.

Things to try:
  1. Select a few words to see the selection color.
  2. Press Ctrl+F (Cmd+F on macOS) and search for "theme" to see find-match colors.
  3. Double-click a word to see occurrence highlights in the overview ruler.
  4. Scroll down to check the scrollbar and minimap slider.
