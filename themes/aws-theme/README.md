# AWS風カラーテーマ

## 概要

AWS マネジメントコンソール風の VSCode カラーテーマです。ネイビーを基調とした UI に、AWS らしいオレンジのアクセントを合わせたダークテーマです。

## 推奨ベーステーマ

ベースのカラーテーマ（`workbench.colorTheme`）は指定していないため、**Dark Modern** などダーク系のテーマと組み合わせて使ってください。このテーマで定義していない色は、ベーステーマの色になります。

## テーマを適用する方法

### 方法1: ワークスペースファイルを使う（推奨）

**AWS風テーマを使いたい場合:**

1. `aws-theme.code-workspace` を、使いたいプロジェクトのルートにコピーする
2. `aws-theme.code-workspace` をダブルクリックするか、**ファイル > ファイルでワークスペースを開く...** で開く
3. VSCode が AWS風カラーテーマで起動します

ワークスペースファイルは `"folders": [{ "path": "." }]` となっているため、ファイルを置いたフォルダがそのまま開きます。

**通常のテーマを使いたい場合:**

- プロジェクトフォルダを直接開く（通常通り）
- または他のワークスペースファイルを使う

**メリット:**

- ✅ テーマの切り替えが簡単（開くファイルを変えるだけ）
- ✅ `.vscode/settings.json` に影響しない
- ✅ チームメンバーが選択できる

---

### 方法2: プロファイルを使う（VSCode 1.75以降）

1. `Ctrl+Shift+P` (Mac: `Cmd+Shift+P`)
2. 「Profiles: Create Profile」を選択
3. プロファイル名を「AWS Theme」にする
4. `aws-theme.code-workspace` の `settings` ブロックの中身を、このプロファイルの `settings.json` にコピー

**テーマ切り替え:**

- 左下のプロファイルアイコンをクリック
- 「AWS Theme」と「Default」を切り替え

---

### 方法3: ユーザー設定に直接書く

VSCode のコマンドパレットから：

1. `Ctrl+Shift+P` (Mac: `Cmd+Shift+P`)
2. 「Preferences: Open User Settings (JSON)」を選択
3. `aws-theme.code-workspace` の `settings` ブロックの中身を貼り付ける

すべてのウィンドウに適用されます。必要なときだけ貼り付け、不要になったら削除してください。

## 配色を確認する

このリポジトリの [`examples/`](../../examples/) に、言語ごとのサンプルファイルがあります。

1. このディレクトリの `aws-theme.code-workspace` を開く
2. **ファイル > ファイルを開く...** で `examples/` 内のファイルを開く

## プロジェクトに適用したときのファイル構成

```text
your-project/
├── aws-theme.code-workspace  ← AWS風テーマ付きワークスペース
├── .vscode/
│   └── settings.json         ← プロジェクト共通設定（テーマ設定は含まない）
└── ...
```

## 推奨構成

```jsonc
// .vscode/settings.json（通常のプロジェクト設定のみ）
{
  "editor.tabSize": 2,
  "editor.formatOnSave": true
  // カラーテーマ設定は含めない
}
```

これにより：

- プロジェクトを普通に開いた場合 → 各自のテーマが適用される
- `aws-theme.code-workspace` で開いた場合 → AWS風テーマが適用される

## Git管理の推奨

チームで共有する場合は `aws-theme.code-workspace` をコミットしておくと、メンバーが使うかどうかを各自で選べます。自分だけで使う場合は `.gitignore` に追加してください。

```gitignore
# 自分だけで使う場合
aws-theme.code-workspace
```
